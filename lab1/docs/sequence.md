# Sequence Diagram: Оформление страхового полиса

```mermaid
sequenceDiagram
    participant K as Клиент
    participant M as Менеджер
    participant S as Система расчёта
    participant P as Платёжная система

    K->>M: Подача заявки
    M->>K: Запрос документов
    K->>M: Предоставление документов
    M->>S: Запрос расчёта стоимости
    S-->>M: Предварительная стоимость
    alt Риск высокий
        M->>K: Запрос дополнительных документов
        K->>M: Дополнительные документы
    else Риск стандартный
        M->>K: Окончательное предложение
    end
    K->>P: Оплата полиса
    P-->>M: Подтверждение оплаты
    M->>K: Отправка полиса
```
