# Flowchart: Расчёт стоимости страхового полиса

```mermaid
flowchart TD
    A[Начало] --> B[Ввод данных клиента]
    B --> C{Возраст водителя < 25?}
    C -- Да --> D[Коэффициент 1.8]
    C -- Нет --> E{Стаж вождения < 3 лет?}
    E -- Да --> F[Коэффициент 1.5]
    E -- Нет --> G[Коэффициент 1.0]
    D --> H[Расчёт базовой стоимости]
    F --> H
    G --> H
    H --> I{Есть ДТП за год?}
    I -- Да --> J[Коэффициент 1.4]
    I -- Нет --> K[Коэффициент 1.0]
    J --> L[Итоговая стоимость]
    K --> L
    L --> M[Конец]
```
